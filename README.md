# LLM Fintech Security Lab

An LLM-powered spending assistant, built to be attacked and then hardened.

## What this covers
- Prompt injection via transaction data
- Cross-user data leakage
- Excessive agency (an AI that can move money)
- Insecure output handling

Findings are mapped to the OWASP Top 10 for LLM Applications.

## Stack
Laravel, React (TypeScript), MySQL, Redis

## Status
🚧 In progress: threat model first, then the vulnerable build, then the fixes.
